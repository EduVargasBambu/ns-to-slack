- Fase 4, pieza 1 (23 nov): `gpv_slack_signature_lib` (HMAC v0 con el Signing Secret de API Secrets) y gateway `customscript_gpv_slack_gateway_sl` (externo, ejecuta como Administrador; **pendiente** rol mínimo `customrole_gpv_slack_gateway` antes de PROD). - Vías de aprobación (decidido 23 nov): los directivos **tendrán usuario de NS**, así que la vía principal es el DM de Slack con enlace al **Centro de Autorización interno** (sesión de NS). Si NetSuite cambia el filtro, opción B: Worker → RESTlet con TBA.
